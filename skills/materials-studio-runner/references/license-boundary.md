# Materials Studio license boundary

Materials Studio is optional external proprietary software and is not part of this repository.

- Users must obtain, install, activate, and operate it under their own applicable license.
- This repository distributes only independently written interoperability instructions, manifests, parsers, and launcher code.
- Do not commit installers, binaries, vendor scripts/assets, manuals, activation data, license files, server credentials, or private support materials.
- Do not bypass license checks, modify license infrastructure, or retry license failures indefinitely.
- If authorization is uncertain, prepare inputs only or route a supported molecular task to the open PySCF backend.
