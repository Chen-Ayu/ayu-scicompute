# ORCA license boundary

ORCA is an external numerical engine and is not part of this repository.

- Do not commit or redistribute ORCA executables, helper binaries, archives, manuals, or license files.
- Require users to obtain ORCA from its official source and determine whether academic or commercial terms apply to their use.
- Do not describe ORCA itself as open source.
- Describe this repository as open workflow code with an optional user-supplied ORCA backend only after the repository owner selects a valid license.
- If a fully open-source engine is required, implement and validate a separate PySCF or Psi4 adapter instead of relabeling ORCA.
