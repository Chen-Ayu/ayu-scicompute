# Five-minute demonstration

1. Show the five Skills, general orchestrator and maturity-aware capability matrix.
2. Enter a Chinese request for a finite molecule or metal-complex calculation.
3. Show the generated task contract, unresolved chemistry, selected current backend, adapter maturity, method decision, and acceptance criteria.
4. Run engine preflight and input dry-run.
5. Launch a small approved smoke job or show a running state with PID/log growth.
6. Show normal termination, parser summary, results CSV, quality checks, and Chinese conclusion.
7. Switch to a polymer/MD request and show routing to a user-supplied Materials Studio backend.
8. Enter a bulk-metal band-structure request and show that VASP is identified as the roadmap route while this release safely remains `prepared-only`.
9. End with license boundaries and the rule that missing evidence can never become `completed`.

For a public presentation, use synthetic structures. Keep unpublished research cases in a private evidence package.
